## Full description (max 4000 · 732 used)

```
MobileSpinRouletteは、スマホ・タブレット・デスクトップ向けの無料オープンソースルーレットです。仮想ポイントのみを使います。現金ギャンブル、購入、払い出し、賞品はありません。

できること
• 欧州式テーブル（0が1つ、37ポケット）と米国式テーブル（0と00、38ポケット）
• インサイド／アウトサイドベットと欧州式レーストラックのコール
• フェルトのマグネットスナップ：ストレート、スプリット、コーナー、ストリート、シックスラインなど
• 再ベット、ダブル、取り消し
• 戦略クリエイター：最大24レイアウト、タップ1回で一手を配置
• セッション統計とスコア推移
• 音楽・効果音・ホイールアニメーションはオフにできます
• 9言語：英語、イタリア語、スペイン語、ブラジルポルトガル語、フランス語、ドイツ語、韓国語、日本語、中国語
• インストール可能なPWA。初回読み込み後は端末キャッシュで遊べます

遊び方
チップを選び、フェルトをタップして Spin を押します。新しいプロフィールは仮想ポイント 2,000,000 から始まります。スコアが 0 になると、新しいゲームでその額が戻ります。スコア、設定、戦略はこの端末に残ります。アカウントも解析もありません。

オープンソース
ソフトウェアは GNU GPL v3 以降です。音楽と Inter フォントは元のライセンスのままです。ソース: https://github.com/orfeomorello/OpenSource-Mobile-Spin-Roulette

カジノではありません
娯楽と練習専用です。お金を得ることも、引き出すことも、チップを買うこともできません。
```
