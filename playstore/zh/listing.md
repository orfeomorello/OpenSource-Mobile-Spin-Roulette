## Full description (max 4000 · 511 used)

```
MobileSpinRoulette 是一款面向手机、平板和电脑的免费开源轮盘游戏。只使用虚拟积分。没有真钱赌博、购买、提现或奖品。

你可以做什么
• 欧式桌（单个 0，37 格）和美式桌（0 与 00，38 格）
• 内注与外注，以及欧式跑道呼叫
• 台面磁吸：直注、分注、角注、街注、六线等
• 再押、加倍、撤销
• 策略编辑器：最多 24 套布局，一键放下整手
• 对局统计与积分曲线
• 音乐、音效和轮盘动画均可关闭
• 九种语言：英语、意大利语、西班牙语、巴西葡萄牙语、法语、德语、韩语、日语、中文
• 可安装的 PWA；首次加载后可从设备缓存游玩

怎么玩
选择筹码，点台面，再按 Spin。新档案从 2,000,000 虚拟积分开始。积分为 0 时，开一局新游戏会恢复该数额。积分、设置和策略只留在本机。没有账号，也没有分析。

开源
软件采用 GNU GPL v3 或更新版本。音乐和 Inter 字体保留原许可。源码：https://github.com/orfeomorello/OpenSource-Mobile-Spin-Roulette

这不是赌场
仅供娱乐和练习。不能赢钱、提现或购买筹码。
```
