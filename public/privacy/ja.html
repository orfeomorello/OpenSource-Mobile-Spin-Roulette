プライバシーポリシー

最終更新: 2026年8月13日

MobileSpinRoulette は仮想ポイントのみを使用します。 現金ギャンブル、購入、換金、賞品、アカウントはありません。

データの収集

本アプリは個人データを収集、送信、販売、共有しません。分析、広告 SDK、追跡技術、アカウント、遠隔のゲームデータサーバーはありません。

端末に保存されるデータ

スコア、設定、言語、保存した戦略、現在のゲームセッションはブラウザのローカルストレージに保存されます。バックアップを書き出さない限り、このデータは端末に残ります。

操作と保持

設定 → あなたのデータ から、ローカルデータの書き出し、取り込み、削除ができます。アプリの削除やサイトデータの消去でも削除される場合があります。本プロジェクトはサーバー上のコピーを保持しません。

端末機能とネットワーク

アプリは任意の振動フィードバックと、進行状況のためのブラウザ保存領域を使うことがあります。ゲーム資産と任意の音楽はアプリと同じホストから読み込まれます。GitHub リンクはアプリを離れ、GitHub 自身のプライバシーポリシーが適用されます。

未成年者と模擬ギャンブル

本アプリは娯楽と戦略の検証のためにルーレットを模擬します。保護者は、居住地の法令のもとでこのギャンブル題材が未成年者に適切かを判断してください。

変更と連絡先

重要な変更はこのページに新しい改定日とともに掲載します。プライバシーに関する質問は GitHub の Issue トラッカーへ送れます。公開 Issue に機微な個人情報を書かないでください。
